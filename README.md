# EXPERT MACHINERY — прототип сайта

Каталог промышленного оборудования и сервиса для рынка **Казахстана** (домен `.kz`).
Next.js 15 (App Router) + TypeScript + Tailwind CSS + framer-motion.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

```bash
npm run build   # прод-сборка
npm run start   # запуск прод-сборки
```

## Структура

```
src/
  app/
    page.tsx                    # главная
    catalog/page.tsx            # уровень 1: типы оборудования
    catalog/[group]/            # уровень 2: позиции внутри типа (фильтры, поиск, сортировка)
    catalog/[group]/[slug]/     # уровень 3: карточка товара (SSG)
    industries/  service/  about/  contacts/
  components/
    site-header.tsx             # шапка: навигация, RU/KZ/EN, Instagram, телефон, кнопка заявки
    site-footer.tsx             # тёмный подвал, WhatsApp и Instagram
    request-modal.tsx           # модальное окно заявки + провайдер (useRequestModal)
    catalog-explorer.tsx        # поиск, пилюли подтипов, сайдбар фильтров, сортировка
    product-card.tsx  request-form.tsx  cta-band.tsx  ui.tsx  logo.tsx
  lib/
    catalog.ts                  # данные: компания, группы, товары, отрасли, услуги, преимущества
    i18n.tsx                    # словари RU / KZ / EN + провайдер языка + склонения
public/
  expert-machinery-logo.jpg     # логотип от заказчика
```

## Каталог: три уровня

`Каталог` ➔ `Тип оборудования` ➔ `Товар`

| Группа | Позиций | Статус |
| --- | --- | --- |
| Мотор-редукторы | 7 | вальные, цилиндрические, червячные, планетарные, промышленные |
| Насосы | 25 | центробежные, вертикальные, многоступенчатые, циркуляционные |
| Муфты | 1 | гидромуфты |
| Фильтры | — | раздел в наполнении |
| Масла и смазки | — | раздел в наполнении |
| ДВС и запчасти | — | раздел в наполнении |

Пустые разделы открываются, но вместо списка показывают «Раздел в наполнении»
и кнопку заявки. Позиции переносятся из TECHPRO (`github.com/707fa/tecpro`),
фото — с сайтов производителей (домены прописаны в `next.config.mjs`).

## Языки

**RU** (по умолчанию), **KZ**, **EN**. Выбор сохраняется в `localStorage`.
Интерфейс, группы, отрасли, услуги, преимущества и подписи характеристик
переведены на три языка. Описания товаров пока существуют в RU/EN — в казахском
показываются на русском (fallback в `pick()`), достаточно дописать поле `kk`
в `src/lib/catalog.ts`.

## Дизайн

Арт-дирекшн собран по референсу заказчика, с правками после обсуждения:

- **фон белый**, тёмная тема не используется;
- фирменные цвета — тёмно-синий `#1B2432` и оранжевый `#F0562A` с логотипа;
- на внутренних страницах — общая «линия»: растянутое фоновое фото под
  полупрозрачной белой панелью с заголовком;
- крупная типографика в обычном регистре, тёмные врезки (цифры компании,
  «Почему выбирают нас»), модальное окно заявки.

| Токен | Цвет | Использование |
| --- | --- | --- |
| `paper` | `#FFFFFF` | основной фон |
| `surface` | `#F5F7FA` | подложки под фото и чередование секций |
| `ink` | `#1B2432` | тёмные секции, футер, текст |
| `flame` | `#F0562A` | акцент, кнопки, надзаголовки |
| `muted` | `#5C6A7E` | вторичный текст |
| `line` | `#E4E7EC` | границы |

## Блоки главной

1. Hero-слайдер (3 кадра) с заявкой и переходом в каталог.
2. Тёмная полоса цифр компании (проекты, штат, лет на рынке, приём заявок).
3. Каталог по типам: большая карточка + нумерованный список из 6 групп.
4. Логотипы предприятий Казахстана (сейчас — заглушки).
5. «Почему выбирают нас» — 6 критериев.
6. Отрасли.
7. Блок заявки: модалка, WhatsApp, телефон.

## Связь

Заявки: модальное окно (Имя, Телефон, Компания, E-mail, Сообщение) + прямая
кнопка WhatsApp. В шапке — Instagram, в подвале — WhatsApp и Instagram.
