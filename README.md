# EXPERT MACHINERY — прототип сайта

Каталог промышленных редукторов, мотор-редукторов, насосов и муфт.
Next.js 15 (App Router) + TypeScript + Tailwind CSS + framer-motion.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

```bash
npm run build   # прод-сборка (42 статические страницы)
npm run start   # запуск прод-сборки
```

## Структура

```
src/
  app/
    page.tsx              # главная: hero, категории, популярные серии, отрасли, процесс, CTA
    catalog/              # каталог с фильтрами и поиском
    catalog/[slug]/       # карточка товара (SSG, 33 страницы)
    industries/           # отрасли
    service/              # сервис и подбор
    about/                # о компании
    contacts/             # контакты + форма
  components/
    site-header.tsx       # шапка: навигация, RU/KZ/EN, телефон, кнопка заявки
    site-footer.tsx       # тёмный подвал в 4 колонки
    request-modal.tsx     # модальное окно заявки + провайдер (useRequestModal)
    catalog-explorer.tsx  # поиск, пилюли категорий, сайдбар фильтров, сортировка
    product-card.tsx      # карточка товара
    request-form.tsx      # встроенная форма (страница контактов)
    ui.tsx                # Eyebrow, SectionHeading, ButtonLink, InnerHero, StatsBand
  lib/
    catalog.ts            # данные каталога (33 позиции, 7 категорий, отрасли, услуги)
    i18n.tsx              # словари RU / KZ / EN + провайдер языка
public/
  expert-machinery-logo.jpg  # логотип от заказчика
```

## Языки

Три языка: **RU** (по умолчанию), **KZ** (казахский), **EN**. Выбор сохраняется в
`localStorage`. Интерфейс, категории, отрасли, услуги и подписи характеристик
переведены полностью на три языка.

Тексты самих товаров (описание, применение, преимущества, значения характеристик)
пока существуют в RU/EN — в казахском они автоматически показываются на русском
(fallback в `pick()` в `src/lib/i18n.tsx`). Чтобы добавить казахский, достаточно
дописать поле `kk` рядом с `ru`/`en` в `src/lib/catalog.ts`.

## Дизайн

Арт-дирекшн собран по референсу заказчика (запись экрана сайта PROLINE):
тёплый светлый фон, крупная «издательская» типографика в обычном регистре,
тёмные врезки, оранжевый акцент и модальное окно заявки.

Что взято из референса:

- hero-слайдер на весь экран с крупным заголовком и счётчиком слайдов;
- тёмная полоса с ключевыми цифрами под hero;
- каталог по типам — большая карточка слева + нумерованный список справа;
- тёмная секция «Почему выбирают нас» с нумерованным списком услуг;
- внутренние страницы: хлебные крошки, надзаголовок вида `SERVICE / ENGINEERING`,
  огромный заголовок и фото-портрет справа;
- каталог: поиск, пилюли категорий, сайдбар `FILTERS`, сортировка, карточки с
  круглой оранжевой стрелкой;
- модальное окно «Оставить заявку» (Имя, Телефон, Компания, E-mail, Сообщение).

Палитра — цвета логотипа на тёплой основе (`tailwind.config.ts`):

| Токен | Цвет | Использование |
| --- | --- | --- |
| `cream` | `#F4F1EA` | основной фон страниц и шапки |
| `ink` | `#161C26` | тёмные секции, футер, основной текст |
| `flame` | `#F0562A` | акцент, кнопки, надзаголовки |
| `muted` | `#6E7480` | вторичный текст |
| `line` | `#E1DCD1` | границы и разделители |

Логотип-файл — вертикальный JPG с широкими полями, компонент `LogoMark`
(`src/components/logo.tsx`) кадрирует его через `object-cover` до символа «EM».
Когда заказчик пришлёт SVG/PNG без полей — просто заменить файл и убрать кадрирование.
