# EXPERT MACHINERY — прототип сайта

Каталог промышленных редукторов, мотор-редукторов, насосов и муфт.
Next.js 15 (App Router) + TypeScript + Tailwind CSS + framer-motion.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

```bash
npm run build   # прод-сборка (42 статические страницы)
npm run start   # запуск прод-сборки
```

## Структура

```
src/
  app/
    page.tsx              # главная: hero, категории, популярные серии, отрасли, процесс, CTA
    catalog/              # каталог с фильтрами и поиском
    catalog/[slug]/       # карточка товара (SSG, 33 страницы)
    industries/           # отрасли
    service/              # сервис и подбор
    about/                # о компании
    contacts/             # контакты + форма
  components/             # шапка, подвал, карточка товара, форма, UI-примитивы
  lib/
    catalog.ts            # данные каталога (33 позиции, 7 категорий, отрасли, услуги)
    i18n.tsx              # словари RU / KZ / EN + провайдер языка
public/
  expert-machinery-logo.jpg  # логотип от заказчика
```

## Языки

Три языка: **RU** (по умолчанию), **KZ** (казахский), **EN**. Выбор сохраняется в
`localStorage`. Интерфейс, категории, отрасли, услуги и подписи характеристик
переведены полностью на три языка.

Тексты самих товаров (описание, применение, преимущества, значения характеристик)
пока существуют в RU/EN — в казахском они автоматически показываются на русском
(fallback в `pick()` в `src/lib/i18n.tsx`). Чтобы добавить казахский, достаточно
дописать поле `kk` рядом с `ru`/`en` в `src/lib/catalog.ts`.

## Данные каталога

Позиции перенесены из проекта TECHPRO (`github.com/707fa/tecpro`): 8 редукторов и
муфт (серия AOKMAN) + 25 насосов (Standart Pompa). Фотографии товаров подгружаются
с сайтов производителей, домены прописаны в `next.config.mjs` (`images.remotePatterns`).
Отраслевые и фоновые фото — Unsplash.

## Фирменный стиль

Палитра взята с логотипа (`tailwind.config.ts`):

| Токен | Цвет | Использование |
| --- | --- | --- |
| `ink` | `#1B2432` | тёмные секции, текст, шапка |
| `flame` | `#F0562A` | акцент, кнопки, оранжевый «клин» из логотипа |
| `sand` | `#F4F6F9` | фон светлых секций |
| `steel` | `#5C6A7E` | вторичный текст |

Логотип-файл — вертикальный JPG с широкими полями, компонент `LogoMark`
(`src/components/logo.tsx`) кадрирует его через `object-cover` до символа «EM».
Когда заказчик пришлёт SVG/PNG без полей — просто заменить файл и убрать кадрирование.
